## Slide 2: What Is AI?

“Artificial Intelligence is the broadest term in this group. It refers to any technique that allows a computer to mimic human intelligence, such as reasoning, problem-solving, perception, or decision-making.” [nasa](https://www.nasa.gov/what-is-artificial-intelligence/)

“AI does not always need to learn from data. Some AI systems are rule-based or symbolic, meaning humans manually define the logic, while others use learning-based methods. The main idea is that the system behaves in a way that seems intelligent.” [nasa](https://www.nasa.gov/what-is-artificial-intelligence/)

“Examples of AI are all around us: chess-playing programs, expert systems, speech recognition tools, and robot navigation systems. These systems may look very different on the surface, but they all fit under the AI umbrella.” [nasa](https://www.nasa.gov/what-is-artificial-intelligence/)

## Slide 3: What Is ML?

“Machine Learning is a subset of AI. Instead of being explicitly programmed with every rule, ML systems learn patterns from data and improve as they see more examples.” [nasa](https://www.nasa.gov/what-is-artificial-intelligence/)

“The key idea is pattern recognition. You give the model training data, and it finds statistical relationships that help it make predictions or decisions later. That’s why ML is so useful for tasks where rules are hard to write by hand.” [nasa](https://www.nasa.gov/what-is-artificial-intelligence/)

“There are three common learning styles: supervised learning, unsupervised learning, and reinforcement learning. Supervised learning learns from labeled examples, unsupervised learning finds hidden structure, and reinforcement learning learns by trial and feedback.” [nasa](https://www.nasa.gov/what-is-artificial-intelligence/)

“Examples include spam filters, recommendation systems, fraud detection, and price prediction. In all of these, the system gets better by learning from data rather than following fixed instructions.” [nasa](https://www.nasa.gov/what-is-artificial-intelligence/)

## Slide 4: What Is DL?

“Deep Learning is a subset of Machine Learning. It uses multi-layered neural networks to learn complex patterns from data, and the ‘deep’ part refers to the number of layers in the network.” [ibm](https://www.ibm.com/think/topics/deep-learning)

“Unlike simpler ML methods, deep learning can automatically extract useful features from raw data. That makes it especially powerful for unstructured data like images, audio, text, and video.” [ibm](https://www.ibm.com/think/topics/deep-learning)

“This is why deep learning powers things like image recognition, natural language processing, self-driving cars, and voice assistants. These tasks involve messy, high-dimensional data that traditional methods often struggle with.” [ibm](https://www.ibm.com/think/topics/deep-learning)

## Slide 5: The Hierarchy

“Here’s the simplest way to remember it: AI is the umbrella, ML is inside AI, and DL is inside ML. So every deep learning system is also machine learning, and every machine learning system is also AI — but not every AI system uses machine learning, and not every ML system uses deep learning.” [academic.oup](https://academic.oup.com/ced/article/45/1/131/6597747)

“This nested structure matters because each layer adds more specialization. AI is the broad goal of intelligent behavior, ML is the method of learning from data, and DL is a specialized ML approach built on neural networks.” [ibm](https://www.ibm.com/think/topics/deep-learning)

“If you remember only one thing from this video, remember this sentence: AI contains ML, and ML contains DL.” [academic.oup](https://academic.oup.com/ced/article/45/1/131/6597747)

## Slide 6: Key Differences

“Let’s compare them side by side. AI is the broadest category, so it can include systems that don’t learn from data at all. ML requires data to train a model, and DL typically needs even larger amounts of data to perform well.” [nasa](https://www.nasa.gov/what-is-artificial-intelligence/)

“Human involvement also decreases as you move from AI to ML to DL. Traditional AI often relies on explicit programming, ML often requires feature engineering, and DL can automatically learn features from raw input.” [nasa](https://www.nasa.gov/what-is-artificial-intelligence/)

“Hardware is another big difference. Basic AI can run on standard CPUs, many ML systems can use a CPU or GPU, and deep learning usually benefits from GPUs or even TPUs because the models are much more computationally demanding.” [ibm](https://www.ibm.com/think/topics/deep-learning)

“So when should you choose each one? Use AI for rule-based or logic-driven tasks, ML for structured data and prediction problems, and DL for large, complex, unstructured data like images or language.” [nasa](https://www.nasa.gov/what-is-artificial-intelligence/)

## Slide 7: Big Picture Summary

“Let’s wrap it up with the full mental model. AI is the umbrella term for machine behavior that appears intelligent. ML is the branch of AI that learns from data. DL is the branch of ML that uses deep neural networks to handle complex pattern recognition.” [nasa](https://www.nasa.gov/what-is-artificial-intelligence/)

“So the relationship is simple: all deep learning is machine learning, and all machine learning is artificial intelligence. But the reverse is not true — many AI systems do not learn, and many ML systems are not deep learning.” [academic.oup](https://academic.oup.com/ced/article/45/1/131/6597747)

“If you can remember that nesting structure, you’ll never confuse these terms again. AI is the goal, ML is the learning approach, and DL is the neural-network-powered version of ML.” [nasa](https://www.nasa.gov/what-is-artificial-intelligence/)
